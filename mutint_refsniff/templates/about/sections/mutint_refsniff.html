Identify a reference genome from reads. A tab on the Import data page, offered while an experiment has no reference: drop one FASTQ or name an SRA run, and the first 16 MB of it is sketched against RefSeq. The answer is a ranked table of the closest genomes — organism, average nucleotide identity, how complete the match is — and the best one can be imported as the experiment's reference with one click, as the assembly it belongs to rather than as a single sequence.

What leaves the deployment is a sketch: a few kilobytes of k-mer hashes, sent to BBTools' RefSeq sketch server at JGI. No read and no assembled sequence is sent, and nothing identifies who asked. The tool is sendsketch.sh from bioconda's bbmap, which brings a JDK with it; reads named by an SRA accession are fetched from ENA over HTTPS, and the assembly for each hit is looked up at NCBI Datasets. The work runs on the task queue, one run per experiment at a time.
